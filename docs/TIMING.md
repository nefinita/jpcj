# TIMING.md — 时间轴（公共调息 / 调息 / 吟唱）设计

> 状态：**设计稿（Draft）**。双族段位表已确认；加速阈值表、吟唱缩放规则、CD 加速、dot 加速等待取证。
> 实现**推迟到数据齐备**后一次性落地（决策 B）。

## 1. 目标

把连招从「无时间的技能序列」升级为**记时连招**：给定固定技能序列，按公共调息(GCD)、
技能调息(CD)、吟唱(读条) 排出每个技能的实际释放/结算时刻，并据此产出
**伤害-时间曲线、TTK 分布、窗口击杀率**。

## 2. 时间单位

- **帧**（整数）：`frame_rate = 16`（16 帧 = 1 秒）。
- 所有时间量（GCD / CD / 吟唱）以**帧**计，避免浮点累积误差。
- 游戏显示值 `n/16` 秒（如 19/16 = 1.1875 → 显示 1.19）。

## 3. 加速（haste）

- **输入**：`haste_rating`（加速等级）。
- **映射**：`haste_rating` → **段位 `tier ∈ {0..5}`**（上限 5 段），经**阈值表**。
- 段位离散，公共调息按段位**查表**（不用连续公式）。
- **下限 = 5 段（满加速）**。

## 4. 门派时间参数（表驱动）

```toml
[timing]
frame_rate           = 16
gcd_frames_by_tier   = [ ... 6 项 ... ]   # 段 0..5 的公共调息（帧）
haste_affects_cd     = false              # 该门派加速是否影响技能CD
```

**两族门派（已确认）**：

| 族 | 段 0 | 段 1 | 段 2 | 段 3 | 段 4 | 段 5 |
|---|---|---|---|---|---|---|
| 1.5s 族（多数门派） | 24 | 23 | 22 | 21 | 20 | 19 |
| 1.0s 族（部分门派） | 16 | 15 | 14 | 13 | 12 | 11 |

（秒值 = 帧/16：1.5s 族 1.50→1.19；1.0s 族 1.00→0.69）

## 5. 每技能字段

```toml
[[skill]]
...
cast_frames     = 0      # 吟唱（帧，0 = 瞬发）
cooldown_frames = 0      # 技能调息（帧）
gcd_frames      = 0      # 公共调息占用覆盖（0 = 用 [timing] 表）
off_gcd         = false  # 是否不触发公共调息
```

## 6. 调度模型（确定性）

```
t = 0; gcd_ready = 0
gcd_eff = gcd_frames_by_tier[tier]

for s in 序列:
    start    = max(t, s.cd_ready, gcd_ready)
    cast_end = start + cast_eff(s)          # 瞬发时 = start
    # 事件：
    #   start    → 触发公共调息（gcd_ready = start + gcd_eff）
    #   cast_end → 结算命中伤害
    #   dot      → 自 cast_end 起，每隔 interval 跳一次
    if !s.off_gcd: gcd_ready = start + gcd_eff
    s.cd_ready = start + cd_eff(s)          # cd_eff 受加速影响否由 haste_affects_cd 决定
    t = cast_end
```

- **读条起手触发公共调息**，伤害在**吟唱结束**结算。
- 瞬发即刻结算并触发公共调息。

## 7. dot 时间轴

- 命中瞬间结算**命中伤害**。
- 之后每隔 `interval` **跳一次**（首跳在 `命中 + interval`），逐跳铺到时间轴上。
- `interval` 是否受加速影响：**默认否**（待定）。

## 8. 输出与指标

- 时间轴事件 `[(帧, 技能, 伤害)]` 与**累计伤害-时间曲线**
- 蒙特卡洛（沿用现有会心 / dot 逐跳独立随机模型）：
  - **TTK 分布**（P50 / P90 / 直方图）
  - **窗口击杀率** `P(TTK ≤ 窗口)`（如 10 / 15 / 20s）
- **每 GCD 期望伤害**（强度指数）
